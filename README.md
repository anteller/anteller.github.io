# クイズ集（択一 / 複数選択 / 単語帳）

ブラウザだけで動く暗記・復習用アプリです。ジャンルごとに問題を管理し、出題→結果→復習（間違いのみ再挑戦）までをスムーズに回せます。

## 特徴

- **3モード**
	- **択一**: 1つ選ぶ
	- **複数選択**: 複数選ぶ（正解は1つ以上）
	- **単語帳**: 表/裏/解説で暗記（既知/未知の記録）
- **ジャンル管理**: ジャンル追加・並べ替え・リネーム・削除
- **問題管理**: 追加/編集/複製/削除、検索（タグ/問題文/選択肢）
- **要チェック**: マークした問題だけ出題
- **統計**: 正答率/既知率、回答数の表示・リセット
- **エクスポート/インポート（JSON）**: 自作問題のバックアップ・移行
- **ローカル保存**: localStorage に保存（サーバ不要）

## 使い方（起動）

1. `index.html` をブラウザで開きます。
	 - VS Code を使う場合は Live Server 等で開くと更新が楽です。

## 基本操作

### モード切替

ホーム画面で「択一 / 複数解答 / 単語帳」を選びます。

### 出題

1. ジャンルを選ぶ
2. 出題数（または全て）を選ぶ
3. 解く

### 結果

- 正解数（/既知数）と、正解した問題/間違えた問題を表示します。
- **間違えた問題だけ再挑戦**できます（ある場合のみ）。

## キーボード操作

### 共通

- `1`〜`9`: 選択肢を選ぶ
- `0`: 「わからない」

### 複数選択

- 手動進行モード時、ボタンが表示されている場合に `Enter` / `Space` で「回答確定/次へ」を実行します。

### 単語帳

- `Enter` / `Space`: 表/裏の切り替え
- `←`: 知っていた
- `→`: 知らなかった

## 問題の管理

### 追加/編集

- **択一/複数選択**: 問題文＋選択肢（正解を選択）＋解説（任意）＋タグ（任意）
- **単語帳**:
	- 「問題文（任意）」＋ 表（front）＋ 裏（back）＋ 解説（任意）＋ タグ（任意）
	- 表/裏が空でも登録できます（ジャンルは必須）。

### 検索

管理画面の検索欄で、タグ/問題文/選択肢/カード内容をまとめて検索できます。

## エクスポート / インポート（JSON）

### エクスポート

管理画面で `JSONエクスポート` を押すと、**現在選択中のジャンル1つ分**を JSON で保存できます。

- エクスポート時に「統計を引き継ぐか」を確認します。
	- **はい**: 正答率/既知率などの統計も含めて出力
	- **いいえ**: 統計を 0 にして出力
	- **× / Esc / 背景クリック**: エクスポートを中止

### インポート

管理画面で `JSONインポート` を押してファイルを選びます。

- 取り込み先は **現在選択中のジャンル** です（「(すべて)」表示中は不可）
- 取り込み後は「置換」か「追加」を選べます
- モードが異なるデータは、取り込めない/変換できない場合があります
	- 択一⇄複数は、変換できる場合のみ取り込みます
	- 単語帳は単語帳形式のみ取り込みます

## 設定

- 進行モード（自動/手動）
- 自動の待機秒数
- 出題数の候補
- テーマ（OS追随/ライト/ダーク）
- Undo 表示時間
- 低正答率モードの出題率調整（PF）

## データ保存について

- 保存先はブラウザの **localStorage** です（同じ端末・同じブラウザに保存されます）。
- モード別に保存領域が分かれています（択一/複数選択/単語帳）。

## トラブルシューティング

- **表示が更新されない/古い見た目になる**:
	- ブラウザの強制リロード（キャッシュ破棄）を試してください。
- **データを全部初期化したい**:
	- 設定画面の「全データリセット」を実行してください（元に戻せません）。
